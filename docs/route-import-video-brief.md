# Video brief: Import a Strava or Wikiloc route into TrailReplay

This is a production brief for a video agent or editor. Make one beginner-friendly screen recording for the **Automatic** section of the [main tutorial](https://trailreplay.com/tutorial) and the [GPX import guide](https://trailreplay.com/gpx-download-guide). Both pages use the same import walkthrough and will show the same video. The video must teach the actual current workflow, not a mockup.

## Ready-to-use assignment for the video agent

> Create a clear, captioned desktop tutorial titled **“Import a Strava or Wikiloc route into TrailReplay.”** Record the real TrailReplay tutorial and real route pages in Chrome. Show how to save the single **Send to TrailReplay** bookmark, how to use it from Strava and Wikiloc, and what to do when the bookmarks bar is hidden. Explain that Wikiloc does **not** require a login, while Strava requires a signed-in account with access to export the activity. Show the route arriving in a **new TrailReplay tab, already loaded**. End with the Manual GPX option and a simple troubleshooting reminder. Follow the script and accuracy notes below. Deliver a 16:9 master, captions, a transcript, and a poster frame. Do not claim that clicking the button installs the bookmark automatically.

## Audience and outcome

The viewer has a route on Strava or Wikiloc but has never used a bookmarklet. After watching, they should know exactly what to save, where to click on the source site, what should happen in TrailReplay, and where to find help if automatic import fails. Use plain language: call it a **bookmark** in the narration, and only introduce “bookmarklet” in an optional caption.

Target length: **2–3 minutes**. Record at desktop resolution with the browser and button text large enough to read at 1080p. Use a deliberate cursor, brief pauses after each click, and zooms only when a control would otherwise be hard to see. Include on-screen captions throughout. Show the final video without private account details, notifications, browser extensions, or unrelated tabs.

## Preparation before recording

1. Use the current version of the [TrailReplay tutorial](https://trailreplay.com/tutorial) or the local preview of this branch. Open its **How to import a route → Automatic** section. The [GPX import guide](https://trailreplay.com/gpx-download-guide) shows the same section.
2. Use a Strava activity belonging to the recording account that can actually be exported as GPX. Sign in to Strava. Hide the account holder’s name, profile photo, precise home location, and any sensitive activity details.
3. Use a public Wikiloc trail with a fully loaded map. **Do not sign in to Wikiloc for this demonstration.** A route like [Aneto desde Vallhibierna por los ibones de Coronas](https://www.wikiloc.com/mountaineering-trails/aneto-desde-vallhibierna-por-los-ibones-de-coronas-105740853) can be used if it still loads and imports when recording.
4. Start with no old Strava or Wikiloc importer bookmarks. If one exists, replace it with the current **Send to TrailReplay** bookmark. This one bookmark works on both sites.
5. Check that Chrome permits the TrailReplay tab to open from both source sites. If Chrome blocks a pop-up, allow it and repeat the click before recording the successful take.
6. Perform the complete Strava and Wikiloc imports once before recording. Do not substitute a manually uploaded GPX while narrating the automatic workflow.

## Suggested full voiceover

“Here’s how to bring a Strava activity or Wikiloc trail into TrailReplay. You only need to set this up once, on a desktop browser.

Open the TrailReplay tutorial and find **How to import a route**. Choose **Automatic**. This orange **Send to TrailReplay** link becomes your importer. If you use the bookmarks bar, drag the link onto the bar. If the bar is hidden, show it with Command, Shift, B on Mac, or Control, Shift, B on Windows or Linux. You can hide it again afterward.

You can also keep the bar hidden while setting it up. Click **Copy bookmark code**, create a new bookmark in Chrome’s Bookmark Manager, name it **Send to TrailReplay**, and paste the code into the bookmark’s URL field. The tutorial lists those steps too. Clicking the orange link on the tutorial page copies the code; it does not install the bookmark for you.

Now open a Strava activity that you can export. Make sure you are signed in to Strava. Select your saved **Send to TrailReplay** bookmark. TrailReplay opens in a new tab with the route loaded.

For Wikiloc, open a trail page and wait for its map to load. You do not need to log in to Wikiloc. Select that same bookmark, and the trail opens in a new TrailReplay tab. If your bookmarks bar is hidden, open the bookmark from Chrome’s bookmarks menu instead.

If a route does not import, allow the new TrailReplay tab and try again. You can also choose **Manual** in the guide to download and upload a GPX file. From there, edit your route and make your replay.”

## Accuracy and recording rules

- **One bookmark, two sites.** It recognizes a Strava activity page or a Wikiloc trail page. It is not a general importer for every route website.
- **A real saved bookmark is required.** A normal click on the orange link in TrailReplay copies its code for manual setup. It does not automatically add anything to Chrome or import the route from that page.
- **Use it on the source route page.** Do not activate it on TrailReplay’s tutorial page, a Strava feed, or a Wikiloc search results page.
- **Strava:** use a signed-in session and an activity the account can export. Avoid implying every public Strava activity is exportable.
- **Wikiloc:** no login is needed for the automatic import; wait for the map to load. Do not show Wikiloc’s Download menu as part of the automatic method. That menu belongs to the Manual method.
- **Result:** show a **new** TrailReplay tab with the imported route already present. The automatic method does not ask the user to save a GPX file first.
- **Browser:** demonstrate Chrome on a desktop. The bookmark workflow is not described as working inside the Strava or Wikiloc mobile apps.
- **Privacy:** the bookmark reads route data in the browser and passes GPX data between the source tab and the TrailReplay tab. Avoid saying TrailReplay stores the route on its servers.
- **Fallbacks:** if the new tab is blocked, allow pop-ups for the source site and try again. If the route cannot be imported, show **Manual** in the same guide. Keep troubleshooting brief in the main video.
