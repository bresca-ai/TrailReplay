# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/bresca-ai/TrailReplay/security/advisories/new). Do not open a public issue for a security-sensitive report.

Include the affected URL or component, clear reproduction steps, impact, and any safe proof of concept. Do not include customer GPX data, media, credentials, or tokens.

We will acknowledge reports within 7 days, investigate privately, and coordinate disclosure and a fix before publishing details.

## Supported versions

Security fixes are applied to the latest production release and `main`. Older releases are not maintained unless explicitly stated in their release notes.
